# Gang Sheet Builder releases

Signed Windows installers for Gang Sheet Builder. The source is private.

Download the latest `Gang.Sheet.Builder_*_x64-setup.exe` from [Releases](https://github.com/thirdfloor/gang-sheet-builder-releases/releases/latest). Installed apps update themselves from here: each release carries a `latest.json` and installers signed with the app's update key, and the app refuses anything unsigned.
